# HLA Typing from Bulk RNA-seq Using Arcas-HLA

## Overview

This directory contains HLA allele typing results generated from bulk RNA-seq data using Arcas-HLA. The objective was to infer HLA genotypes for participants included in the SARS-CoV-2 CITE-seq study to support downstream T-cell and TCR analyses.

Arcas-HLA performs HLA typing directly from RNA-seq data and reports high-resolution HLA alleles for both Class I and Class II loci.

All samples completed successfully without warnings or errors. Review of the output files did not identify any obvious issues with the inferred genotypes.

## Directory Contents

### HLA Genotype Calls

For each sample, three output files are provided:

#### `*.genotype.json`

Primary HLA typing results.

Contains the inferred HLA alleles for each locus, for example:

```json
{
  "A": ["A*01:01:01", "A*02:01:01"],
  "B": ["B*08:01:01", "B*35:02:01"],
  "C": ["C*04:01:01", "C*07:01:01"]
}
```

These files represent the final genotype calls and are the primary output for downstream analyses.

---

#### `*.genes.json`

Gene-level support metrics generated by Arcas-HLA.

These files contain read support and abundance estimates for individual HLA genes and are primarily useful for quality control and troubleshooting.

---

#### `*.genotype.log`

Execution log generated during HLA typing.

Contains runtime information, software messages, and diagnostic output.

No warnings or errors were observed in the analyzed samples.

## Summary Report

### `arcas_run.html`

Interactive HTML report summarizing all samples.

The report includes:

* Complete HLA genotype table
* Class I HLA calls (HLA-A, HLA-B, HLA-C)
* Two-field simplified HLA calls
* Allele frequency summaries across samples
* Genotype heatmaps
* Sample-level inspection of notable calls

This report provides the primary summary of the cohort-level HLA results.

---

### `arcas_run.qmd`

Quarto source document used to generate the HTML report.

Can be modified and re-rendered if additional samples are analyzed.

---

## Analysis Scripts

### `run_arcas.slurm`

SLURM submission script used to execute Arcas-HLA on the HPC cluster.

Responsible for running HLA typing on each sample.

---

### `parse_hits.R`

R script used to parse individual genotype outputs and generate summary tables used in the final report.

## Interpretation Notes

### Class I HLA Alleles

The most relevant loci for CD8 T-cell analyses are:

* HLA-A
* HLA-B
* HLA-C

These alleles can be used for:

* TCR interpretation
* Antigen presentation analyses
* Epitope prediction
* HLA stratification of participants

### Class II HLA Alleles

Additional loci reported include:

* HLA-DQA1
* HLA-DQB1
* HLA-DRB1

These may be useful for CD4 T-cell analyses and antigen presentation studies.
